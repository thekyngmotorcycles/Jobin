# Jobin wordmark
Retro connected script, based on Lobster by Pablo Impallari (SIL Open Font License; see assets/licenses/Lobster-OFL.txt). The word is capitalized Jobin.
SVG contains glyph outlines: no external fonts, network request or fallback typography. PNG exports are 1800 x 600, with identical 3:1 canvases. White lettering has subtle offset depth and top lighting; transparent white and dark ink variants accompany the black plaque.
JobinWordmark uses contain sizing and a fixed aspect ratio. Shared screen headers, Live discovery and the app font-loading screen use the plaque. This is the React loading screen, not a replacement for the native OS launch screen. No native splash configuration or runtime dependencies changed; suitable for an OTA update.
